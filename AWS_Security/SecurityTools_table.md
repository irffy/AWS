# AWS Security Services - Complete Table

| AWS Security Service               | Purpose                                                                 | Example Use Case                                                                                  |
|------------------------------------|-------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------|
| **AWS KMS (Key Management Service)** 🔑 | Securely manages and encrypts sensitive data using cryptographic keys.   | Encrypt customer data stored in Amazon S3, RDS, EBS using KMS keys.                               |
| **AWS Secrets Manager** 🔒         | Securely stores and rotates API keys, passwords, and database credentials. | Store a database password securely and retrieve it in an AWS Lambda function.                     |
| **AWS Certificate Manager (ACM)** 📜 | Issues and manages SSL/TLS certificates for securing websites and applications. | Secure a web application running behind AWS ALB (Application Load Balancer).                      |
| **VPC Flow Logs** 📊               | Captures network traffic logs for monitoring and security analysis.      | Monitor all ingress and egress traffic in a VPC to detect unauthorized access.                    |
| **AWS WAF (Web Application Firewall)** 🚧 | Protects applications from SQL injection, XSS, and bot attacks.          | Block SQL injection attacks on an API Gateway using AWS WAF rules.                                |
| **AWS Shield** 🛡️                  | Protects against DDoS (Distributed Denial-of-Service) attacks.           | Use AWS Shield Advanced to mitigate DDoS attacks on CloudFront & Route 53.                        |
| **AWS Network Firewall** 🌐        | Provides deep packet inspection firewall for VPC security.               | Block malware traffic and restrict unauthorized IPs within a VPC.                                 |
| **AWS Macie** 🔍                   | Uses AI to discover and classify sensitive data (PII, financial, health data) in Amazon S3. | Detect credit card numbers stored in an S3 bucket and alert security teams.                       |
| **AWS Config** 📜                  | Monitors AWS resource configurations and ensures compliance.             | Detect if an S3 bucket is publicly accessible and trigger a security alert.                       |
| **AWS CloudTrail** 📜              | Logs all AWS API activity for auditing and forensic investigation.       | Track who deleted an EC2 instance or modified an IAM policy.                                      |
| **AWS GuardDuty** 🚔               | Uses AI/ML to detect security threats, including unusual logins, compromised credentials. | Detect suspicious API requests from a new country or unknown IP.                                  |
| **AWS Inspector** 🕵️              | Scans EC2 instances, Lambda, and containers for vulnerabilities.         | Identify unpatched software running on an EC2 instance.                                           |
| **AWS Firewall Manager** 🔥        | Centrally manages AWS WAF, AWS Shield, and AWS Network Firewall policies. | Enforce WAF rules across multiple AWS accounts to block bot attacks.                              |
| **AWS Security Hub** 🛡️           | Provides a centralized security dashboard for compliance and threat detection. | Check CIS, PCI DSS compliance across all AWS accounts in AWS Organizations.                       |
| **AWS IAM Access Analyzer** 🛠️    | Detects overly permissive IAM policies that expose resources.            | Identify if an IAM role grants public access to S3, KMS, or Lambda.                               |
| **AWS Detective** 🔍               | Investigates AWS security threats using AI and log analytics.            | Trace anomalous API requests from a hacked AWS account.                                           |
| **AWS Systems Manager (SSM)** 🚀   | Manages EC2 patching, remote access (without SSH), and automation.       | Use Session Manager to securely access EC2 instances without SSH keys.                            |
| **Amazon Cognito** 🔑              | Provides user authentication, MFA, and OAuth-based login.                | Securely authenticate users in a mobile app with Google/Facebook sign-in.                         |
