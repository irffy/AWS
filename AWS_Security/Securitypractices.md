# AWS Security Best Practices

| Category                | Best Practices                          | AWS Services                                      |
|-------------------------|-----------------------------------------|---------------------------------------------------|
| **IAM Security**        | Least privilege, MFA, IAM roles         | IAM, AWS IAM Identity Center (SSO), STS           |
| **Data Protection**     | Encryption, Secrets Manager, S3 security| AWS KMS, Secrets Manager, Macie                   |
| **Network Security**    | VPC security, WAF, Shield               | AWS WAF, AWS Shield, Network Firewall             |
| **Monitoring & Alerts** | CloudTrail, GuardDuty, Config           | CloudTrail, CloudWatch, Security Hub              |
| **Compliance & Governance** | AWS Organizations, SCPs             | Organizations, Audit Manager, Control Tower       |
| **Automation**          | Lambda auto-remediation                 | AWS Lambda, Systems Manager                       |
